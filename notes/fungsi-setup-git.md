# Fungsi dari setup git

1. ## History & Safety
> Setiap kali kamu selesai bikin fitur, kamu commit. Kalau besok kode rusak, kamu bisa *git diff* lihat apa yang berubah, atau *git checkout* balik ke versi yang masih jalan. Itu safety net.

2. ## Latihan workflow engineer 
> Software engineer sehari-hari kerja dengan git: *add → commit → push → PR → merge*. Semakin awal kamu terbiasa, semakin alami nantinya.

3. ## Tracking progress 
> Nanti 3 bulan dari sekarang, kamu bisa *git log --oneline* dan lihat 200+ commit. Itu bukti nyata perjalanan kamu dari nol sampai engineer.

### *Singkatnya* : git = undo button + time machine + portfolio bukti kerja keras.
