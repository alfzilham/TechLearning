# Workflow Belajar Harian

## Struktur 6 Jam

| Waktu | Aktivitas |
|-------|-----------|
| Sesi 1 (90 menit) | Baca materi + dokumentasi + catat konsep |
| Istirahat (15 menit) | Jauh dari layar |
| Sesi 2 (90 menit) | Coding praktek sesuai tugas |
| Istirahat (30 menit) | Makan / jalan / recharge |
| Sesi 3 (90 menit) | Coding lanjutan / mini project |
| Istirahat (15 menit) | Jauh dari layar |
| Sesi 4 (60 menit) | Review kode, catat pelajaran, rencana besok |

## Alur 1 Hari

```
Baca Materi → Mengerj → Stuck → Coba Debug 15m → Minta Bantuan → Selesai → Review
```

## Cara Belajar yang Efektif

1. **Feynman Technique**: Jelaskan konsep dengan bahasa sendiri. Jika tidak bisa menjelaskan dengan sederhana, berarti belum paham.
2. **Active Recall**: Tutup materi, coba tulis ulang dari ingatan.
3. **Deliberate Practice**: Kerjakan soal yang sedikit di atas level kemampuan.
4. **Code Every Day**: Lebih baik 2 jam per hari daripada 14 jam di akhir pekan.

## Daily Log

Di akhir setiap hari, catat:
- Apa yang dipelajari hari ini
- Apa yang masih membingungkan
- Satu hal yang "aha moment"

Simpan di folder `docs/journal/` jika ingin.
